CHAPTER 02

문 사장님의 호통: 72 DPI와 300 DPI의 차이

밤 10시 25분 · 모니터 해상도 비교창
유나야, 그냥 모니터에 뜬 화면을 캡처 도구로 잘라서 문 사장님께 보내면 안 되냐? 그게 제일 빠르잖아!
원장님, 그러다 문 사장님한테 등짝 맞으세요! 모니터 캡처는 72~96 DPI(인치당 점 개수)밖에 안 돼서 종이에 인쇄하면 글자 테두리가 계단처럼 다 깨져 나와요. 인쇄소 납품은 무조건 300 DPI 기준 벡터 PDF로 뽑아야 해요!
체험 2 · A4 인쇄 해상도(DPI) 및 픽셀 규격 비교기 300 DPI 규격을 선택하세요

📌 짚고 가기: 웹 화면(Screen)과 인쇄물(Print)의 해상도 공식

A4 용지(210mm × 297mm)를 인쇄소 품질(300 DPI)로 출력하려면 가로×세로 2480 × 3508 픽셀 또는 글꼴이 벡터로 내장된 PDF가 필요합니다. HTML 성적표를 만들고 @page { size: A4; margin: 12mm; } CSS 규칙을 적용해 PDF로 바로 구워내면 활자가 칼처럼 선명하게 인쇄됩니다.
