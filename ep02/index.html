CHAPTER 02

AI에게 안방 열쇠까지 주실 건가요?

오전 10시 40분 · 노트북 보안 설정 창
유나야, 근데 AI가 내 컴퓨터에 있는 엑셀 파일을 직접 읽고 저장하게 하려면 어떻게 해야 하냐? 혹시 내 컴퓨터 전체를 다 뒤지게 놔둬도 되는 거야?
절대 안 되죠! 손님한테 교무실 책상 하나만 쓰라고 해야지 안방 금고 열쇠까지 주면 어떡해요! AI한테는 딱 지정된 학원 허브 폴더(~/spring-hub/) 하나만 열람할 수 있게 울타리를 쳐줘야 해요.
체험 2 · MCP 로컬 파일 경로 승인/차단 훈련 판정: 0 / 4

AI 에이전트가 파일 접근을 요청합니다. 격리된 학원 허브(~/spring-hub/) 내부만 허용(Allow)하고 나머지는 모두 차단(Block)하세요.

📌 짚고 가기: MCP (Model Context Protocol)와 Root Isolation

MCP 파일시스템 도구를 연결할 때는 반드시 루트 디렉터리 격리(Root Isolation) 원칙을 지켜야 합니다. ~/spring-hub/만 마운트하면 AI는 그 상위 폴더(바탕화면, 공인인증서, 시스템 설정)의 존재조차 볼 수 없어 사고가 원천 차단됩니다.
