EPISODE 05 · DAY 4: SIMULATION & DATA DICTIONARY

"동명이인 김민준 둘이 성적이 바뀌었다"

개강 전날 밤 가상 데이터로 돌려본 리허설에서 중2 김민준과 중3 김민준의 성적표가 서로 뒤바뀌었다! 실제 발송 전이었기에 망정이지 하마터면 학원 문을 닫을 뻔한 아찔한 순간. 고유 식별자(Primary Key)와 데이터 사전(Data Dictionary)으로 완벽한 방어막을 친다.

남궁 철 (49세) 봄볕영어 원장 엑셀 VLOOKUP을 항상 '학생 이름'으로만 걸어 쓰다가 동명이인 김민준 함정에 빠져 식은땀을 흘린다.
지유나 (17세) 고2 수강생 · 방송부 개강 전날 모의 시뮬레이션을 제안해 대참사를 막아낸 일등공신. STD-2027-012 학번 체계를 도입한다.
문 사장 (50대) 1층 문인쇄 대표 성적표 봉투 겉면에도 이름 옆에 고유 학번 끝 3자리를 같이 인쇄해야 봉투가 안 바뀐다고 조언한다.
난이도: 중급 (데이터 무결성 & 스키마) 소요 시간: 약 25분 핵심 도구: schema.json, Primary Key, 스트레스 테스트 검증 일자: 2026-10-12

CHAPTER 01

개강 전날 밤의 비명: 두 명의 김민준

1월 3일 (일) 밤 9시 30분 · 봄볕영어 교무실

"으아아악!!" 교무실이 떠나가라 남궁 원장이 비명을 질렀다. 내일 개강을 앞두고 유나가 시킨 대로 가상 데이터 30명분을 넣어 모의 실행을 돌리던 중이었다.

유나야 큰일 났다!! 중3 김민준(94점) 성적표에 중2 김민준(68점) 어머님 전화번호가 찍혀 나왔어! 이거 진짜로 발송했으면 어머님 두 분 다 학원 뒤집어엎으셨을 거다!!
휴, 그래서 제가 개강 전날 밤에 반드시 모의 시뮬레이션(Dry Run)부터 돌려봐야 한다고 한 거예요! 원장님, 컴퓨터한테 '이름(name)'으로 줄 세우라고 하면 대한민국에서 제일 흔한 이름인 김민준, 이서준은 무조건 충돌해요.
오늘부터 봄볕영어의 모든 표는 이름이 아니라 절대로 겹치지 않는 고유 학번(STD-2027-012)을 기준으로 묶어야 해요!
체험 1 · 동명이인 김민준 충돌 디버거 안전한 기준 키로 전환해 보세요

📌 짚고 가기: 기본키 (Primary Key)의 절대 원칙

사람의 이름은 고유하지 않습니다. 학원 자동화에서 모든 CSV와 리포트 파일은 반드시 유일무이한 식별자(예: STD-2027-012)를 첫 번째 열(Primary Key)로 삼아야 동명이인 오발송 사고를 100% 예방할 수 있습니다.

CHAPTER 02

데이터 사전(Data Dictionary)이라는 헌법

밤 9시 55분 · 노트북 스키마 설계창
그런데 유나야, 내가 급하게 엑셀 치다 보면 날짜를 어떤 날은 2027/1/4라고 치고 어떤 날은 1월 4일이라고 치거든. 그것도 문제가 되냐?
엄청 큰 문제가 되죠! 그래서 어떤 칸에 어떤 모양의 글자만 들어갈 수 있는지 적어둔 약속장, 즉 데이터 사전(Data Dictionary)을 만들어 둘 거예요.
체험 2 · 봄볕영어 데이터 사전 규격 매칭기 일치: 0 / 4

각 칼럼(열)에 알맞은 데이터 규격을 드롭다운에서 선택하고 [규격 검증]을 눌러보세요.

1. student_id (고유 학번)
2. test_date (응시 일자)
3. vocab_score (단어 점수)
4. parent_phone (보호자 연락처)

밤 10시 35분 · CSV 검수 화면
체험 4 · 불량 CSV 데이터 지뢰 3곳 색출하기 발견: 0 / 3

아래 CSV 데이터에서 데이터 사전 규격을 어긴 불량 데이터 3곳(붉은 점선)을 클릭해 교정하세요.

student_id,name,test_date,vocab_score
STD-2027-012,김민준,2027-01-04,94
학번없음_이서준,이서준,2027-01-04,82

🖥️ 실제 도구 검증 · schema.json 기반 무결성 검증 스크립트

워크스페이스의 verified/schema.json과 실제 출결 데이터를 대조하여 동명이인 김민준 2명을 고유 학번으로 완벽히 분리 식별한 결과입니다.

$ cat verified/schema.json { "schema_version": "1.0.0", "academy": "봄볕영어 (031-555-0142)", "primary_key": "student_id", "id_pattern": "^STD-2027-[0-9]{3}$", "date_format": "YYYY-MM-DD", "required_fields": ["student_id", "name", "grade", "status", "parent_phone"] }
